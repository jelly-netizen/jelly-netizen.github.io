Key Concepts

Communication over the internet relies on several protocols to move data between devices. These concepts explain what happens behind the scenes every time you open a web page.

URL

A Uniform Resource Locator is the address of a page on the web, such as https://www.youtube.com. Entering one in the address bar is how a user starts loading a page.

HTTP and HTTPS

Hypertext Transfer Protocol lets a browser request pages from a server and receive them. HTTPS is the secure version, which encrypts the data sent between the browser and the server.

TCP

Transmission Control Protocol delivers data reliably between devices. It breaks data into packets and makes sure they are reassembled in the correct order.

IP

Internet Protocol gives every device a unique address, called an IP address, and routes packets to those addresses.

DNS

The Domain Name System works like a phonebook. It turns easy to remember names like www.youtube.com into the numeric IP addresses computers use.

Browser Engine

The part of a browser that interprets HTML, CSS and JavaScript and draws the page. The three major engines are Chromium, WebKit and Gecko.

JavaScript

The language used with HTML and CSS to build web apps. Introduced in 1995, it was slow until Google's V8 engine (2008) compiled it to machine code just in time. Today it lets browsers run complete applications.
