Browser History

Web browsers have been around since 1990. In that time they have grown from simple document viewers into full application platforms.

What Is a Web Browser?

Its Purpose

  • A browser fetches content and displays it on a user's device.
  • The user starts by entering a URL in the address bar.
  • The page is retrieved over a protocol called HTTP or HTTPS.
  • How a page is rendered depends on which browser you use.
  • A browser is not a search engine, but modern browsers build one into the address bar.

How It Works

  1. The browser acts as a client and sends a request to a server.
  2. The server sends back the source files (HTML, CSS, JavaScript, images).
  3. The browser interprets these files and renders the page.
  4. Several protocols carry the data between client and server. See Key Concepts.

Early Browsers

Researchers were working on browsers as early as the 1980s, building on hyperlinked applications. These early tools left a lot to be desired.

WorldWideWeb (1990)

  • The first web browser, later renamed Nexus.
  • Created by Tim Berners-Lee while he was working at CERN.
  • It never had a large user base, but it showed what was possible and led to many more browsers shortly after.

NCSA Mosaic (1993)

  • The first mainstream browser.
  • The first to show images inline with text instead of in a separate window.
  • Popular for its interface, reliability, PC support and simple install.
  • Lost most of its users to Netscape Navigator and Internet Explorer by 1997.
  • It shaped the idea of what a browser should be.

The Browser Wars

First Browser War (1995–2001)

Internet Explorer vs. Netscape Navigator

  • Netscape started with about 75% of the market but was much smaller than Microsoft.
  • Internet Explorer came free with Windows, and Internet Explorer 3 matched Netscape's features.
  • Netscape struggled to compete and was bought by America Online (AOL).
  • Internet Explorer reached about 90% user share in 2001.

Second Browser War (2004–2017)

Internet Explorer vs. Firefox vs. Chrome

  • Netscape open-sourced its browser and handed it to the Mozilla Foundation, which led to Firefox.
  • Netscape was discontinued in 2008, and its users were directed to Firefox.
  • Google Chrome launched in 2008 and quickly gained users.
  • Chrome was the most used browser by 2012 and had over 60% of users by 2017.
